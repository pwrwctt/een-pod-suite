# Orchestrated workflow

## Complete profile
Intake → Draft → Title/Summary → Keywords → Independent Review.

## Narrow tasks
- type/eligibility → intake only
- main text → drafter
- Title/Summary → optimiser
- taxonomy → classifier
- readiness → reviewer
- queries/renewal → dissemination skill

The reviewer must be last for a final/submission-ready request.

## Published profile by operator-supplied detail URL
Read the operator-supplied exact detail URL → verify the displayed POD Reference → extract public fields → independent quality review when requested.

If only a number or name is supplied, request the exact detail URL. Do not search for the profile.
