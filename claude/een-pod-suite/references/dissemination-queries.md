# POD dissemination and saved queries

Source basis: Managing Queries for Widgets and Ticker, last updated 13 December 2024.

Treat this as a **2024 UI snapshot**.

## Query dashboard

The guide describes three tabs:
- Partnering Opportunities
- Events
- Widget/Ticker

Partnering Opportunities and Events queries are used for Email notification queries.
Widget/Ticker queries are separated into their own tab.

## Role permissions described in the guide

- **Advisors:** view Widget/Ticker queries.
- **Partner Administrators:** create, edit or delete Widget/Ticker queries.

Verify current permissions if the user asks about today's live system.

## Create a query

1. Open Queries.
2. Choose Partnering Opportunities or Events.
3. Apply filters.
4. Select `Save as a query`.
5. Complete mandatory Name and Description.
6. Choose target:
   - **Email**; or
   - **Widget/Ticker**.

### Email
Set:
- Recipient (`Me` or `Client`);
- Frequency;
- Next execution / start date.

### Widget/Ticker
A required **Contact Choice** is shown to designate an adviser/contact for displayed opportunities/events.
Saving produces embeddable HTML code and a Copy to clipboard option.

## Edit a query

Editable details described by the guide:
- Name;
- Description;
- Contact Choice (Widget/Ticker);
- Recipient (Email);
- Frequency (Email);
- Next execution (Email).

To edit result filters, open the query results, change filters and save the query again.

## Migration note from the 2024 enhancement

The guide says existing organisational queries were automatically split into:
- recipient-based Email queries; and
- Widget/Ticker queries for website embedding.

Do not assume this migration behaviour is still relevant to a newly configured 2026 environment.
